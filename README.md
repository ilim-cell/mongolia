## How to run the website
> [!IMPORTANT]
> PLEASE READ THESE INSTRUCTIONS CAREFULLY.

1) Install [npm](https://nodejs.org/dist/v24.18.0/node-v24.18.0-x64.msi) by clicking on the link
2) Install [git](https://github.com/git-for-windows/git/releases/download/v2.54.0.windows.1/Git-2.54.0-64-bit.exe)
3) Open a terminal
``` PowerShell
cd [location to clone to]
git clone https://github.com/ilim-cell/mongolia.git
npm install
npm run dev
```
